STOCKSMART INVENTORY PAGE SETUP

Files included:
- inventory.php
- db.php
- inventory_style.css
- stocksmart_inventory_database.sql

Step 1:
Copy these files into your project folder:
xampp/htdocs/stocksmart_project/

Step 2:
Start XAMPP:
- Apache
- MySQL

Step 3:
Open phpMyAdmin:
http://localhost/phpmyadmin

Step 4:
Click Import and choose:
stocksmart_inventory_database.sql

Step 5:
Click Go.

Step 6:
Open the inventory page:
http://localhost/stocksmart_project/inventory.php

Important:
Do not double-click inventory.php.
Always run PHP files using localhost.

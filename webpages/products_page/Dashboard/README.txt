StockSmart Dashboard Project Setup

1. Install XAMPP.
2. Open XAMPP Control Panel.
3. Start Apache and MySQL.
4. Copy the folder named stocksmart into:
   xampp/htdocs/

5. Open browser:
   http://localhost/phpmyadmin

6. Click Import.
7. Choose stocksmart_database.sql from this folder.
8. Click Go.

9. Open the dashboard:
   http://localhost/stocksmart/dashboard.php

Important:
- Do not open dashboard.php by double-clicking it.
- Always open it through localhost.
- The dashboard values come from MySQL database using PHP.
